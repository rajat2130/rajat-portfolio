## Setup GitHub Pages

1. Push this repo to `github.com/rajat2130/rajat-portfolio`
2. Go to **Settings → Pages**
3. Source: **Deploy from branch** → `main` → `/ (root)`
4. Save — site goes live in ~1–2 minutes
